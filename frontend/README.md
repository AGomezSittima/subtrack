# Subtrack frontend

React 19 + Vite 8 + TypeScript 6.0, TanStack Router (file-based) and Query, Tailwind CSS 4, shadcn/ui on Base UI, react-i18next (`en`, `es`) and Temporal (polyfilled at entry). nginx serves the production build and proxies `/api` to the active backend.

## Layout

| Path                    | Contents                                                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `src/routes/`           | File-based routes, kept thin. `src/routeTree.gen.ts` is generated by the router plugin (committed, never edited) |
| `src/features/<area>/`  | Feature code: `api/` (query hooks), `components/`, `schemas/`                                                    |
| `src/components/ui/`    | shadcn/ui components (our code; the only place that imports Base UI)                                             |
| `src/components/`       | Shared composite components (`DatePicker`, `MoneyInput`, …)                                                      |
| `src/lib/`              | Adapters behind our own interfaces: `api/` (openapi-fetch client), `i18n/`, `utils.ts` (`cn`)                    |
| `src/locales/{en,es}/`  | Translations; every key exists in both (checked by `locales.test.ts`)                                            |
| `src/styles/global.css` | Tailwind entry and design tokens (`:root`, `.dark`, `@theme inline`)                                             |

## Commands

```sh
pnpm dev          # Vite dev server; /api is proxied to a stack started with `just up <profile>`
pnpm build        # type-check and build to dist/
pnpm lint         # ESLint (--max-warnings 0) + tsc
pnpm test         # Vitest
pnpm exec shadcn add <component>   # add a shadcn/ui component
```

Lint guards worth knowing: `i18next/no-literal-string` (no hard-coded UI text), no `Date` outside `src/components/date-picker.tsx`, no `Temporal.Now` (time comes from the clock), and no Base UI imports outside `src/components/ui/`.

The Docker image is built from the repository root: `docker build -f frontend/Dockerfile .`
